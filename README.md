# 🤖 AI-Powered Automated Data Exploration

An AI-powered web application that makes **data exploration easier using natural-language queries**. Users can upload a dataset and ask questions about their data. The application uses **Groq LLM** to generate Python/Pandas code automatically and executes the generated code to return the requested result.

## 🚀 Features

* 📂 Upload datasets for analysis
* 🐼 Data processing using **Pandas**
* 🤖 AI-powered analysis using **Groq LLM**
* 💬 Ask questions about your dataset using natural language
* 🧠 Automatically generates Python/Pandas analysis code
* 📊 Displays dataset previews and analysis results
* 🌐 Simple web interface using **Flask**
* 🔍 Uses the existing dataset columns to generate relevant analysis

## ⚙️ How It Works

The application follows these steps:

```text
Upload Dataset
      ↓
Data Preprocessing
      ↓
Display Dataset Preview
      ↓
User Enters Natural-Language Query
      ↓
Groq LLM Generates Pandas Code
      ↓
Generated Code Executes on DataFrame
      ↓
Display Analysis Result
```

## 💡 Example

After uploading a dataset, the user can ask questions such as:

```text
What is the average glucose level?
```

or

```text
How many records are present in the dataset?
```

or

```text
What is the average value of each numerical column?
```

The application sends the user's question and the available DataFrame columns to the Groq LLM. The generated Python code is then executed on the uploaded DataFrame.

## 🔐 API Key

This project requires a **Groq API key**.

You can obtain an API key from the official Groq platform.

⚠️ **Never upload your API key to GitHub.**

Do not hard-code your API key inside the source code. Use an environment variable or enter it through the application's interface.

Example:

```text

```

## 🧠 AI Component

The application uses a **Groq-hosted LLM** to convert natural-language questions into executable Python/Pandas code.

The prompt provides the model with the exact columns available in the uploaded DataFrame and instructs it to:

* Use only available columns
* Use the existing `df` DataFrame
* Use Pandas for analysis
* Store the final result in a variable named `result`
* Return executable Python code

This allows users without advanced Python knowledge to perform basic data analysis using natural language.

## ⚠️ Security Note

The application executes Python code generated by an LLM using `exec()`.

For a production application, this should **not be exposed without proper sandboxing and security controls**. Generated code should be validated and executed in an isolated environment.
